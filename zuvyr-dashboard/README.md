# ZUVYR · True Automation Core — Dashboard

لوحة تحكم داكنة (RTL) تعرض الوحدات الستة للمحركات متعددة الوكلاء، وترتبط بالـ Gateway المحلي عبر `/api/zuvyr-dashboard`.

## المكوّنات

| الملف | الوظيفة |
|---|---|
| `index.html` / `styles.css` / `app.js` | الواجهة (HTML + CSS + JavaScript بدون أي تبعيات) |
| `server.js` | خادم Node بلا تبعيات: يقدّم الواجهة، ويمرّر `/api/*` إلى الـ Gateway، ويقدّم ملفات الوسائط |
| `gateway/app.py` | الـ Gateway (Flask) كما هو، ويعمل على `127.0.0.1:5000` |

## الوحدات الستة

1. **محرك الوسائط اللامتناهي** — قائمة السيناريوهات واللغات المدعومة (AR / EN / ES / FR).
2. **محرك الرسوم المتحركة** — مشغّل فيديو عمودي مع عداد دقائق المشاهدة والجدول الزمني (Shorts 60s، Long 5/10/13 دقيقة).
3. **الأطفال والموسيقى** — مراقبة بروتوكول الأطفال وتصفية الأصول حسب الفئة (فيديو، صور، نصوص، صوت، 3D).
4. **العلامة والصور المصغّرة** — معرض الصور المصغّرة مع عرض مكبّر.
5. **ذكاء الأعمال** — عدادات المشاهدات وRPM والأدسنس والأفلييت، وحالة التكامل مع AdSense.
6. **المُنسِّق ذاتي التطور** — زر **Master Run** وحالة درع الأمان وسجل التشغيل.

## التشغيل

```bash
# 1) الـ Gateway (المنفذ 5000)
pip install -r zuvyr-dashboard/gateway/requirements.txt
python zuvyr-dashboard/gateway/app.py

# 2) الواجهة (المنفذ 8080)
ZUVYR_MEDIA_ROOT=/path/to/your/project node zuvyr-dashboard/server.js
```

ثم افتح `http://127.0.0.1:8080`.

### متغيرات البيئة

| المتغير | الافتراضي | المعنى |
|---|---|---|
| `PORT` | `8080` | منفذ الواجهة |
| `BACKEND_URL` | `http://127.0.0.1:5000` | عنوان الـ Gateway الذي يُمرَّر إليه `/api` |
| `ZUVYR_MEDIA_ROOT` | غير مضبوط | المجلد الذي يحتوي `videos_pool/` و `scripts_pool/` و `3d_pool/`، ويُستخدم لتشغيل الفيديو والصور |

## لماذا يمرّ الطلب عبر `server.js`؟

- المتصفح يطلب `/api/zuvyr-dashboard` من نفس المصدر، فلا حاجة لتفعيل CORS في الـ Gateway.
- الواجهة لا تستدعي `127.0.0.1` مباشرة من المتصفح، فتعمل أيضاً داخل المعاينة المستضافة.

## ما الذي يعرضه الـ Gateway الحالي وما الذي ينقصه

الـ Gateway الحالي يعيد قوائم أسماء الملفات والإعدادات النصية فقط. لذلك:

- **العدادات الحية (المشاهدات، RPM، أرباح الأدسنس، الأفلييت)** تظهر `—` حتى يرجع الـ Gateway هذه الحقول كأرقام في `financial_analytics`: `views`, `rpm`, `adsense_earnings`, `affiliate_earnings`. عند وجودها تُعرض تلقائياً مع تحريك للأرقام.
- **زر الترجمة الفورية** معطّل لأن الـ Gateway لا يملك نقطة خدمة للنصوص أو الترجمة.
- **زر Master Run** يرسل `POST /api/zuvyr-dashboard/master-run`. إن لم يوجد المسار يعرض الواجهة رسالة 404 واضحة في السجل.
- قوائم الملفات في الـ Gateway مكتوبة يدوياً (محاكاة) ولا تُقرأ من القرص. إن أردت عرضاً حقيقياً فاستبدلها بـ `os.listdir` على المجلدات الفعلية.

## الأمان

- الخادم مصمم للتشغيل المحلي فقط. لا تعرضه على الإنترنت دون طبقة مصادقة.
- ملفات الوسائط تُقرأ فقط من `ZUVYR_MEDIA_ROOT` مع منع الخروج عن المجلد وتجاهل الملفات المخفية.
- كل النصوص القادمة من الـ API تُعرض عبر `textContent` لا `innerHTML`.
