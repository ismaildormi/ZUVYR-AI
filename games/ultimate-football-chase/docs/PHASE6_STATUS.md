# Phase 6 — economy and Market source status

**Guest greybox demo and read-only catalog implemented; real economy/IAP NOT operational or accepted.** The PDF requires ordinary earned Coins, rare/free-or-purchased premium Gems, exclusive gem/real-money items, normal coin-only items, a Market, and Season Pass. Its IAP price table is a *reference*, not a purchasable offer without platform store configuration. No Firebase wallet ledger, server run validation, product identifiers, real store SDK, receipt validation or asset-ready character/board catalog is present. Nothing here claims a real purchase, premium currency balance or account entitlement.

## Implemented now

- `StoreCatalog` is six ordinary / four premium original fictional concepts (60/40 proposed split). Only three additional **recolors of the existing generic Greybox outfit** can be bought/equipped, for **75 / 100 / 125 guest demo coins** respectively — all **provisional playtest prices**. The three starter colors (teal/amber/violet) remain free. Other characters/boards/kits are visibly **PREVIEW ONLY**; no premium/real-money product can be bought or equipped. No real footballers, team badges or copies of recognizable uniforms.
- Characters/Kits/Boards vendors in the Market browse the 10-item catalog after **five separately completed stages**. Authenticated players see a read-only catalog and “ACCOUNT WALLET UNAVAILABLE”; they cannot use a guest's demo balance. Hub/runner show the selected greybox recolor for the local guest only. Account Hub snapshots never contain guest demo currency or tint IDs; account/guest switching restores original saved outfit.
- Run coins are visibly labeled **unverified** and, on a finished **guest** run only, up to **200 local demo coins** are credited into `ufc.practice.guest.store.v1`. This is not a trusted payout. A generated run ID makes duplicate credit attempts for the same run idempotent within a **64-run local window**. The practice balance cap is **100,000**. Local PlayerPrefs is editable, unencrypted and strictly unsuitable for prize/premium/purchase authority. No key/gem/real-money grants, paid item, or credit on signed-in accounts. Coins shown in a signed-in run are an unverified counter only, **not deposited to an account wallet**.
- `IAccountEconomyGateway` defines a future server-issued wallet read, idempotent coin purchase and restore purchases boundary; the only implementation **fails closed** until a trusted server ledger, receipt verification and authenticated Store APIs exist. Client Hub stages/coins cannot be converted into actual account currency. Do not extend `firebase/firestore.rules` to accept direct wallet writes.
- `Phase6Tests.cs` covers catalog split, guest-only/idempotent/capped demo credits, guest-only store access and corruption/invalid entitlement rejection. Tests **have not been run in Unity**.
