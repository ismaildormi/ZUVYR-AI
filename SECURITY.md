# Security Policy

ZUVYR treats security and permission boundaries as product requirements.

Please **do not disclose vulnerabilities, credentials, tokens, customer information or working exploit details in a public GitHub issue**. Use GitHub's private vulnerability-reporting/security-advisory flow when it is available for this repository; otherwise contact the repository owner privately so the report can be triaged before public discussion.

For the security architecture and V1 baseline, see [docs/SECURITY.md](docs/SECURITY.md).

Never commit production secrets to this repository.
