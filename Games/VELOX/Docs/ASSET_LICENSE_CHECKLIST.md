# Asset & audio licence checklist (release gate — all boxes required)
This project ships with **empty** art/audio slots on purpose. "Zero copyright risk" is a process, not
a property of code: before any store submission, for every file placed in `Assets/Art`, `Assets/Audio`,
`Assets/Textures` or a billboard Texture Slot, record in this table: file · author/source · licence ·
commercial-use proof (invoice / licence URL) · attribution text (also paste into `AudioCatalog.licenseAttributions`).

| Slot | Rule |
|---|---|
| NEO character model + animations | Original commission or CC0/commercial licence; keep the contract |
| City environment / obstacles | Original or licensed; **never** railway/train/track assets from any existing runner game |
| Music / SFX | CC0 or commercial licence only; no ripped game audio |
| Billboard creatives | Your own brand or signed sponsor licence for in-game placement |
| Fonts (TMP) | Open Font Licence or commercial licence |

Also: original logo/wordmark "VELOX" only, bundle id `com.zuvyr.velox`, run a trademark search for
"VELOX" in game classes before submission, and keep store screenshots free of third-party brands.
> Note: this checklist reduces risk; it is not legal advice and no code can guarantee 0% legal risk.
