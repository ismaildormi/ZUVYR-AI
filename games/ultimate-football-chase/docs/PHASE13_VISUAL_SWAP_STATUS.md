## First implementation on our own Unity code

- New `VisualCatalog` ScriptableObject exposes an optional original humanoid prefab, 24m station-tile prefab, seven visual obstacle prefab slots, and shared font/button/backdrop colours. The Editor scene builder creates `Assets/_Game/Resources/VisualCatalog.asset` if absent, without replacing an existing asset; both HUDs use the optional font/colours. Unset references retain existing greybox.
- `RunnerMotor` supports a separate, non-squashed rig root and optional Animator parameters (`Jump`, `Slide`, `Stumble`, `Fall`, `Fly`, `RunSpeed`); root motion is disabled so it cannot override the existing three-lane, swipe, jump/slide, speed and collision rules. `AvatarAppearanceSlots` lets approved kit/skin/headwear renderer slots use the selected Hub profile without tinting the entire prefab.
- `TrackWorld` can display optional separately sourced station and obstacle art while retaining row planning, difficulty, collision thresholds, warning marks and pooling. Any prefab 3D colliders are disabled on instances. Coins, powerups, shop, Hub mannequin and chaser are unchanged greybox. Visual fit/clearance must be checked in Unity on real devices.
- `Assets/_Game/Art/` documents proposed folders and `docs/ASSET_PROVENANCE.csv` is an empty audit register. There are **no production art assets** in this patch. `Phase13VisualSwapTests.cs` adds authored Editor tests for fallback, replacement hit box/warnings, lane motion and isolated appearance slots.
