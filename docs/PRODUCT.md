# ZUVYR Product

ZUVYR is being built as a unified AI platform where chat, research, media creation, coding, voice, computer control and agents work as one product.

## Core product surfaces
- **Chat & multimodal** — conversations, files, images, memory, sources and tool use.
- **Research & web** — evidence-aware research and connected information workflows.
- **Images** — generation, reference workflows, editing, variations, background removal, upscale and history.
- **Video** — generation, reference video, editing/VFX, subtitles, dubbing, enhancement and export.
- **Voice & audio** — STT, TTS, realtime voice and audio workflows.
- **Code Studio** — projects, files, secure execution, terminal, build/test/preview and deploy workflows.
- **ZUVYR IP** — permission-bound computer/device control with explicit grants, STOP/undo and auditability.
- **Agents & automations** — durable scheduled and task-based execution backed by Brain Kernel.
- **Workspace & library** — reusable projects, creations, artifacts, lineage and context.
- **Integrations** — scoped external connections with explicit consent and revocation.

## Product principles
ZUVYR is user-outcome oriented: capabilities should connect into useful end-to-end actions rather than isolated demos. Identity, permissions, context, artifacts and usage accounting are shared foundations across the product.

V1 is not declared ready because a UI or code path exists. Production evidence, denial/failure paths, cleanup and the canonical acceptance matrix determine readiness.
