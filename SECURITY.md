# Security Policy

ZUVYR treats security and permission boundaries as product requirements.

Please **do not disclose vulnerabilities, credentials, tokens, customer information or working exploit details in a public GitHub issue**. Report sensitive findings privately to the repository owner so they can be triaged before public discussion.

For the security architecture and V1 baseline, see [docs/SECURITY.md](docs/SECURITY.md).

Never commit production secrets to this repository.
